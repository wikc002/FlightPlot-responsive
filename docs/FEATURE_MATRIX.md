# 功能与边界清单

这份清单定义 0.5.8 的公开行为。修改代码时，应保证每项都有明确入口、结果和错误闭环。

| 功能 | 入口或触发 | 输入 | 可见结果 | 边界与错误处理 | 验证 |
|---|---|---|---|---|---|
| 打开日志 | 工具栏、文件菜单、命令行、拖放 | BIN/LOG/ULG/PX4LOG | 新日志页、字段树、参数和消息 | 空文件、全零、损坏、未知格式、取消均给出结果且不破坏当前页 | `FormatRegression`、`UiRegression` |
| 多日志页 | 打开、`+`、页关闭按钮 | 多个日志路径 | 每页独立图表、缩放、处理器和消息 | 同一路径去重；打开中可取消；最后一页关闭后回到空状态 | `ArchitectureRegression`、`InteractionRegression` |
| 大 BIN | 打开、缩放、拖动图表 | DataFlash BIN | 快速索引和可见范围曲线 | 截断尾部保留已解析数据；任务可取消；有限堆内存可运行 | `ReaderBenchmark`、`LargeBinBenchmark` |
| 动态字段 | 打开日志、切换日志页 | 文件内 FMT/FMTU 或 ULog schema | 当前文件实际字段完整进入左侧树 | 新消息、实例、数组、float16 和晚到格式定义不依赖版本白名单 | `FieldCatalogRegression` |
| 字段搜索和排序 | 搜索框、展开节点 | 字段名或中文说明 | 过滤结果、C1…C14 自然顺序 | 无匹配时显示空树，不改变已选处理器 | `ProductRegression` |
| 添加处理器 | 工具栏、字段双击、Add、Enter | 处理器类型或字段 | 处理器行和图表曲线 | 已存在且未勾选则重勾；已勾选则高亮；无重复项 | `InteractionRegression` |
| 编辑处理器 | 双击处理器行 | 标题和参数 | 修改当前处理器并重绘 | 参数无效时提示并保留原值 | `UiRegression` |
| 移除处理器 | 工具栏、Delete | 多段高亮或多项勾选 | 一次移除所有目标 | 空选择不弹窗；选择优先级一致 | `InteractionRegression` |
| 移除全部 | 工具栏 | 当前页全部处理器 | 单一确认后清空 | 快速连点只出现一个确认窗口 | `InteractionRegression` |
| 字段颜色 | 工具栏、处理器参数颜色行 | 字段和 RGB | 曲线与底部图例即时变色 | 取消不修改；重复触发聚焦已有窗口 | `InteractionRegression` |
| 选择继承 | 打开相同格式日志 | 处理器、勾选、颜色 | 存在字段自动恢复并绘制 | 不同格式隔离；缺失字段跳过并在状态栏报告 | `UiRegression` |
| 图表 | 勾选、缩放、平移、窗口变化 | 时间范围和数值序列 | 清晰曲线、坐标轴、图例 | NaN、空数据和尖峰不会卡死或丢峰 | `UiRegression` |
| 标记与分钟线 | 顶部复选框 | 可见时间范围 | 数据点与顶部分钟标线 | 极窄和极宽范围限制标记密度 | `UiRegression` |
| 时间模式 | 视图菜单 | 日志起点、启动或 GPS 时间 | 横轴按所选时间显示 | 无 UTC 时使用既有回退逻辑 | `ProductRegression` |
| 参数与日志消息 | 左栏折叠区、日志信息 | reader 元数据 | 延迟填充的表格和详情窗口 | 无日志时禁用；大量消息仍可滚动 | `UiRegression` |
| 预设 | 预设框、保存、删除、导入、导出 | `.fplot` JSON | 处理器配置持久化 | 损坏文件提示；重名行为保持兼容 | `ProductRegression` |
| 导出 | 文件菜单 | 图表、参数、位置序列 | 图片、TXT、KML 或 GPX | 缺字段、无数据、写入失败均提示 | `ProductRegression` |
| 中英文 | 顶部语言按钮 | 当前语言 | 可见文案即时切换 | 不重新打开日志，不改变字段原生键 | `LocalizationRegression` |
| HiDPI 与响应式布局 | 启动、窗口缩放、多屏移动 | 100%–250% 显示缩放 | 字体、图表和对话框清晰且不重叠 | 对话框限制在当前屏幕工作区内 | `UiRegression` |

## 外部兼容约束

- 入口类：`me.drton.flightplot.FlightPlot`。
- 支持扩展名大小写不敏感：`.px4log`、`.bin`、`.ulg`、`.log`。
- 预设格式：`.fplot` JSON；参数导出：文本；航迹导出：KML/GPX。
- Preferences 根节点、处理器名称、菜单路径和中英文文案保持兼容。
- 字段键始终使用日志 schema 原名，本地化只改变显示文本。
